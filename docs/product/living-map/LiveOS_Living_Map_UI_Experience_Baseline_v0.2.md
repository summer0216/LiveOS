# LiveOS Living Map UI Experience Baseline v0.2

> **FROZEN UI EXPERIENCE BASELINE**
>
> 当前属于 UI / Experience Prototype Layer，不代表 Backend / Decision Runtime 已接通。

## Baseline

以下 Living Map UI Experience 已通过验证并冻结：

- **S1–S6 — Living World Decision Loop**
  World → Focus → Unknown → Action → Reality → Attention Moves On。Living World 作为持续存在的体验边界，Reality 更新 Choice，完成的行动消解进 Reality，Attention 随后回到仍然开放的 Choice Field。

- **G1.1 / G3 — Truthful Geographic Grounding**
  Geographic Identity 按可信精度逐级解析；只有具备真实 Geographic Truth 的对象进入 Geographic Projection 与 camera bounds。用户补充的 Reality 可以完成 Resolution Transition，并让原有 Decision Identity 进入真实 Geography。

- **C1 — Compare: Two Possible Lives → Shared Meaning**
  Compare 在同一个 Living World 中发生。两个 grounded Choices 保持真实地理位置，同时成为 Shared Meaning 的视觉端点；比较揭示已知、差异与不确定性，不产生 Score、Ranking 或 Recommendation。

- **C2 — Reality Changes the Comparison**
  Reality 替代 Compare 中的不确定性，更新 Choice viability，结束失效的 Compare Meaning 与 Relationship，并让 World 回到新的稳定状态。

- **Conversation Dissolves into Consequence**
  Conversation 用于表达 Intent 与 Reality；提交内容不成为永久 Chat UI，而由 Living World 直接呈现其结果。

## Freeze Boundary

本基线冻结的是当前已验证的 UI / Experience behavior、visual grammar 与 interaction consequence。它不声明 Backend、AI Runtime、Decision Engine、Memory、Evidence 或持久化能力已经完成集成。
