# LiveOS Development Workflow v1.0

## Workflow
Product Discussion
↓
Frozen Specification
↓
Architecture Review
↓
Product Review
↓
Generate Codex Task
↓
Codex Implementation
↓
Code Review
↓
Manual Acceptance
↓
Freeze
↓
Release

## Rules
- 先定义真实问题，再冻结方案。
- Codex 只负责实现，不负责产品设计。
- Freeze 前必须完成 Review 与 Manual Acceptance。
- 先解决真实问题，再抽象架构。
