# Capability Roadmap

## Phase 1 — Understanding

AI 开始真正理解用户。

### ✅ Sprint17 — Living Model（Completed）

**Capability**

Living Model

**Description**

Runtime 建立统一的用户生活模型。

Living Model：

- Runtime Object
- 不持久化
- 不新增 Store
- 不新增 API
- 不新增 Workspace

Decision Runtime 开始统一消费：

- Living Profile
- Decision Memory

形成：

Living Model

作为 Runtime 第一层 Understanding。

**Result**

AI 不再只是拥有 Profile 与 Memory。

AI 开始形成：

> 对用户生活状态的统一理解。

---

## Phase 2 — Reasoning

AI 开始真正理解自己的决策。

### ✅ Sprint18 — Decision Intelligence（Completed）

**Capability**

Decision Intelligence

**Description**

Decision Runtime 增强推理能力。

新增：

- Advantages
- Risks
- Conflicts
- Trade-offs

保持：

Current Facts

>

Living Model

>

Decision History

Decision Intelligence：

- 不新增 Runtime
- 不新增模型调用
- 不新增 Prompt Pipeline

仍保持：

Single AI Runtime。

**Result**

AI 不只是生成 Decision。

开始：

理解：

为什么这样决策。
